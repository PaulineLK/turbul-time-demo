# turbul-time-demo
Prototype de démonstration de Turbul Time
## Versions en ligne

- [Démo simplifiée pour Kevin](https://paulinelk.github.io/turbul-time-demo/)
- [Prototype complet V2.6.2](https://paulinelk.github.io/turbul-time-demo/prototype/)

Ces versions utilisent uniquement des données fictives.  
Ce sont des prototypes de démonstration : ils ne disposent pas encore de véritable authentification, de persistance des données ni de fonctionnement multi-utilisateur.
